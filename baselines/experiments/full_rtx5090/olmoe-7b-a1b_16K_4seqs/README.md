# olmoe-7b-a1b_16K_4seqs

| Model | Training | Sequence length | Sequences per step | World size | Hardware |
|---|---|---|---|---|---|
| `olmoe-7b-a1b` | full training | 16,384 tokens | 4 (65,536 tokens) | 1 | NVIDIA GeForce RTX 5090, 32 GiB each; 188 GiB of host memory |

These define the experiment: every case of every engine shares them, and they title its figures.

Full training of OLMoE 7B-A1B on one RTX 5090, with four 16K sequences per update, initialized weights and synthetic tokens. Compare throughput, GPU memory and host memory across the three engines.

Generated by `baselines/generate_experiment.py` from the `full` template; `generation.json` records the inputs and the values derived from them. The folder is the experiment: edit it as it needs, and run it with the common runner as [the guide](../../README.md) describes.

## Scenario

| | |
|---|---|
| Model | `olmoe-7b-a1b`, its `mlops` implementation, full |
| Weights and data | initialized weights; synthetic tokens |
| Geometry | 16,384-token sequences, 65,536 tokens per update, 1 GPU |
| Precision | weights bfloat16, masters none, gradients bfloat16, AdamW moments bfloat16; rounding to nearest; the narrow-gradient fusion as each engine defaults |
| Run | 1 warmup and 1 measured updates per case; 8 CPU threads; at most 3600 s a case |
| Sized for | 32 GiB of GPU memory and 188 GiB of host memory: the ShadowSpill budgets, its spill pool and the summary's budgets follow from them |

## Engines

The sweep has 144 cases in order ShadowSpill, DeepSpeed, FSDP2. Microbatches
contain 1, 2 or 4 complete 16K sequences. ShadowSpill searches factor
orderings within each geometry and shares preparation across its five GPU
budgets. FSDP2 compares both gradient-sync modes for every accumulated case;
the single-microbatch geometry has one sync case. Resharding stays enabled
after forward and backward, with no explicit prefetch-depth sweep.

DeepSpeed retains the full-training template: optimizer state is offloaded
to CPU, while parameter residency varies between GPU and CPU.

Each engine's options are the settings its README documents; a matrix holds the engine's own, and the shared settings above join every case.

### shadowspill: 15 cases ([options](../../../engines/shadowspill/README.md))

Every case: `spill_gib` 160, `orderings` "factors".

* 15 cases: `tokens_per_microbatch` 16384, 32768, 65536; `execution_gib` 8, 12, 16, 24, 28

### deepspeed: 54 cases ([options](../../../engines/deepspeed/README.md))

Every case: `zero_stage` 3, `offload_optimizer` "cpu".

* 6 cases: `tokens_per_microbatch` 16384, 32768, 65536; `recompute` 0; `offload_param` "none", "cpu"
* 48 cases: `tokens_per_microbatch` 16384, 32768, 65536; `recompute` 0.25, 0.5, 0.75, 1; `offload_param` "none", "cpu"; `activation_offload` "none", "cpu"

### fsdp2: 75 cases ([options](../../../engines/fsdp2/README.md))

Every case: `offload_policy` "cpu", `reshard_after_forward` true, `reshard_after_backward` true, `forward_prefetch` 0, `backward_prefetch` "auto".

* 60 cases: `tokens_per_microbatch` 16384, 32768; `recompute` 0, 0.25, 0.5, 0.75, 1; `activation_offload` "none", "cpu", "overlapped"; `gradient_sync` "per-microbatch", "last-microbatch"
* 15 cases: `tokens_per_microbatch` 65536; `recompute` 0, 0.25, 0.5, 0.75, 1; `activation_offload` "none", "cpu", "overlapped"

## Running it

From the repository's root, in a tmux window, first the dry run, which validates every case and launches nothing:

```bash
python -u -m baselines.experiment --spec baselines/experiments/full_rtx5090/olmoe-7b-a1b_16K_4seqs/experiment.json --dry-run
```

then the same command without `--dry-run`. A run writes everything into `output/` in this folder, which git ignores. `--engine <engine>` runs one engine and keeps what the others hold; the same command again resumes, `--retry-failed` attempts the failed cases again, and `--overwrite` runs the engines it runs from scratch. The variables' values are recorded in `output/`, so a resume need not repeat them.

## Results

A run ends with `output/summary.md` and the report in `output/report/`. To keep the summary with the experiment:

```bash
python -m baselines.summary baselines/experiments/full_rtx5090/olmoe-7b-a1b_16K_4seqs/output \
  --publish baselines/experiments/full_rtx5090/olmoe-7b-a1b_16K_4seqs/results
```

which writes `results/summary.md` and its figures; `python -m baselines.trace baselines/experiments/full_rtx5090/olmoe-7b-a1b_16K_4seqs/output <engine> <case>` traces one case under Nsight Systems.

# Plan-video command alias

The implementation and CLI reference live with the cut-trajectory tools in
[`../pressurefit_trace/plan/`](../pressurefit_trace/plan/README.md).
Use `python -m tools.pressurefit_trace.plan ...` for new commands.
`python -m tools.plan_video ...` forwards to the same CLI, so previously saved
commands still work. This directory contains no renderer or analysis logic.

# ShadowSpill workloads

Optional model architectures, checkpoint mappings, input processors and training
recipes. Import them as `shadowspill_workloads`. The engine can prepare and run
custom models without installing this catalog.

See the [catalog](src/shadowspill_workloads/MODELS.md),
[training recipes](src/shadowspill_workloads/recipes/README.md), and
[repository setup](../../docs/development/repository.md).
For contributors, [workload organization](../../docs/development/workloads.md)
explains the package hierarchy and the steps for adding a built-in family.
